# UI Quality Rules

- UI must not look like a generic Tailwind template.
- Use a clear visual concept per site.
- Desktop and mobile layouts must both be designed and checked.
- Agent 2.5 must generate design options through the external design model for every site, even when no UI references are provided.
- Agent 5 Design Gate must reject weak visual concepts before Agent 3 starts.
- If Agent 3 generates screenshots from an approved design, Agent 4 must preserve them closely.
- Reserve monetization slots subtly without enabling ads.
