# UI Reference Object Schema

```yaml
ui_reference:
  url: string | null
  desktop_screenshot: string | null
  mobile_screenshot: string | null
  reference_strength: medium
  notes: string
  borrow:
    - color direction
    - card feeling
    - illustration mood
    - layout rhythm
  avoid:
    - exact copying
    - brand assets
    - logos
    - trademarked elements
```
