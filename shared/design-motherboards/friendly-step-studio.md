# Motherboard B — Friendly Step Studio

## Purpose

Use this motherboard for light, repeatable, low-pressure tools where the user generates, randomizes, creates, picks, copies, or saves something.

Good fit:

- randomizer
- generator
- creator
- picker
- name/date/letter/prompt generators
- decision helper
- personal mini-tool
- friendly tool collection

## Visual feel

- Friendly and human.
- Light and approachable.
- Slightly playful, never childish.
- Medium density.
- Rounded cards with warm microcopy.
- Hand-drawn doodles or light-color illustration accents.
- The tool still comes first.

## First viewport pattern

- Short friendly title.
- Short subtitle.
- Card-based step flow:
  1. Set/input
  2. Generate/randomize/create
  3. Copy/save/retry
- Result card has strong presence.
- History, saved items, or tips may appear as secondary cards when useful.

## Content modules

Choose modules by behavior:

- generator: How to use, output options, use cases, tips for better results, FAQ
- randomizer: How to use, randomness rules, repeat/no-repeat options, use cases, FAQ
- creator: How to use, input ideas, output examples, editing tips, FAQ
- picker: How to use, fairness rules, saved choices/history, FAQ

## Asset language

- Hand-drawn doodle, light-color illustration, friendly mini scene.
- Each key step can have a small doodle or visual marker.
- Keep UI text as real HTML text, not inside images.
- Assets must be standalone local files when selected.

## GPT prompt block

Use Motherboard B as a design strategy. Create three distinct implementation-ready UI directions for this exact tool. Keep the page light, friendly, human, and tool-first. Use a step-based flow: set/input, generate/randomize/create, then copy/save/retry. Make the result card visually satisfying and easy to copy. Use hand-drawn doodles or light-color illustrations, but do not make the UI childish, toy-like, or decorative-only.
