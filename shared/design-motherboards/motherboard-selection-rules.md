# Motherboard Selection Rules

Agent 2 makes an initial recommendation. Agent 2.5 owns the final UI motherboard decision.

## Two-step classification

First identify the keyword root:

- calculator
- generator
- checker
- converter
- counter
- tester
- randomizer
- finder
- creator
- file/open/viewer

Then identify the real tool behavior:

- table calculation
- single-result calculation
- text analysis
- file handling
- format conversion
- visual preview
- pass/fail scoring
- issue diagnosis
- random picking
- list generation
- step creation
- practice testing
- copyable output

## Default selection

Use A. Mature Tool Workbench for:

- calculator
- checker
- converter
- file/image/format tools
- privacy/security tools
- text analysis where accuracy matters
- typing/test/benchmark tools
- visual audit tools

Use B. Friendly Step Studio for:

- randomizer
- generator
- creator
- picker
- fun or personal mini-tools
- low-pressure tools where retry/copy/save is the main loop

## Override policy

Agent 2.5 may override Agent 2's recommendation because it owns UI design strategy. It must not silently change product, SEO, legal, or core tool decisions.

Record any override with:

```txt
Agent 2.5 Motherboard Override

Original Agent 2 recommendation:
Agent 2.5 decision:
Override reason:
UI/design risk avoided:
Impact on design generation:
Needs Agent 2 correction: yes/no
```
