# Input Schema

- Agent 2 site brief
- Agent 2 SEO plan
- Agent 2 tool spec
- Agent 2 content plan
- Agent 2 UI reference dossier
- Optional UI reference URLs, screenshots, component images, or illustrations
- Run constraints
- Tool workflow and interactive states
- Realistic dynamic data ranges and worst-case display values
- Long label examples for ingredients, presets, controls, and result metrics
- Minimum readability and touch-target constraints

UI references are optional input. GPT-powered UI design generation is mandatory.

Default fidelity policy:

- Visual restoration target: 90%.
- Local generated PNG/SVG assets are allowed.
- SEO content and final tool functionality are downstream phases and should not be mixed into the design-generation objective.
- Usability is a hard precondition for selecting a design. A visually attractive design that cannot fit realistic data, readable text, clean thumbnails, and usable controls must fail before Agent 3.
