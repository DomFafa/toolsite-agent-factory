# Output Schema

Required outputs:

- `site/`
- `implementation-report.md`
- `changed-files.md`

Each output should include decisions, assumptions, and next-agent handoff notes.

`implementation-report.md` must record:

- Agent 2 Toolsite Page Plan source path.
- `gate-results/page-plan.json` status before route implementation.
- Implemented pages.
- Confirmation that no `optional-not-needed` or `rejected` pages were implemented.
- Any unplanned page proposal that caused Agent 4 to stop instead of implementing it.
