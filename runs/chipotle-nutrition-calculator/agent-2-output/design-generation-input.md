## Design Generation Mode

reference-guided

## UI Goal

Create a bright, premium, food-brand-style Chipotle Nutrition Calculator. The first viewport must be an immediately usable meal builder with live nutrition totals, ingredient cards, portion controls, and presets.

Use original food photography-style ingredient visuals plus light illustrated UI decoration. Keep the calculator useful, fast, and information-dense enough for a user ordering food on mobile.

## Required Screens

- Desktop: calculator-first layout with live totals and rich ingredient selection.
- Mobile: thumb-friendly calculator-first layout with totals visible early and easy ingredient scanning.

## Required Frontend Output

- Runnable static HTML/CSS/JS.
- No backend.
- No external API keys.
- No official image assets.
- First viewport is the tool itself.
- Include enough representative data and interactions to demonstrate the UI.

## Reference Constraints

Borrow:

- Ingredient photography cues from nutrition calculator references.
- Bright food-brand warmth, playful illustration accents, and layout rhythm from Graza.

Avoid:

- 1:1 copying.
- Official logos, official images, trade dress, and exact interactions.
- Dark UI.
- Marketing-first hero.
