# Restoration Rules

## Option B - Focus Ledger

- Preserve the first viewport as a usable typing test.
- Preserve the selected palette, typography scale, metric layout, passage treatment, and input placement.
- Keep all visible text as real HTML text.
- Do not replace CSS-built visuals with screenshots or bitmap backgrounds.
- Do not add login, leaderboard, teacher, premium, certificate verification, or regional exam UI.
- Do not move SEO explanations above the tool.
- Do not add fixed word-count modes in V1.
- Preserve visible focus states and non-color mistake indicators.
- Keep no-image-assets status unless a later user approval explicitly changes the selected design package.
