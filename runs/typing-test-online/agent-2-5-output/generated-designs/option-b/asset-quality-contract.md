# Asset Quality Contract

## Option B - Focus Ledger

Required image slots: none.

This direction intentionally uses no bitmap image assets, no food/preset thumbnails, no raster screenshots, and no external brand artwork. All visual structure is produced with HTML text, CSS, borders, shadows, gradients, and optional inline SVG icons.

Because there are no image slots:

- No raster source-size requirement applies.
- No aspect-ratio matching requirement applies.
- No subject-fill or white-margin risk applies.
- No asset files are expected in `assets/`.
- If this option is selected, `selected-option-assets.zip` is not required because the selected design contains no image slots.
