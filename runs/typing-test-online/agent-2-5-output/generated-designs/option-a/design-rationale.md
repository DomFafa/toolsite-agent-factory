# Design Rationale

## Option A — Benchmark Console

Professional benchmark console with crisp typography, restrained depth, purple/cyan accenting, and a central passage/input workbench.

The direction borrows only broad mood cues from Stripe: precision, restrained depth, confident hierarchy, and metric-forward trust. It borrows only functional coverage from SpeedTypingOnline: a timed test, visible stats, selectable duration/category, restartability, and passage highlighting. The result remains an independent global English typing-test utility with no copied layout, copy, protected text, or brand assets.

Codability is high because the direction relies on CSS, HTML text, and small vanilla JavaScript state changes. It is suitable for Astro visual restoration before later functionality and SEO implementation. This option is traceable to the external ChatGPT response saved in `external-design-evidence/external-response.md`.
