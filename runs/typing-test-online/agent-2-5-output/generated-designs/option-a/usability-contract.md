# Usability Contract

## Option A — Benchmark Console

- The first viewport must expose the full typing workflow: controls, live metrics, passage, input, and restart/new passage actions.
- Changing duration, mode, or difficulty resets the test and visibly updates active state.
- Restart clears input and metrics while preserving selected settings.
- New passage clears input and metrics and advances to a bundled passage.
- Mobile target keeps passage text at 19px and button tap targets at 44px.
- Current character and mistakes are not color-only.
- No optional no-op controls are allowed.
