# Usability Contract

## Option C - Night Calibration

- First viewport is the working typing test, not a marketing hero.
- Desktop controls are at least 36px tall; mobile controls are at least 44px tall.
- Passage text remains readable at `320px` viewport width.
- Metric cards use stable min widths and tabular numbers so values do not shift layout.
- Timer remains idle until the first valid typed character.
- Restart preserves selected duration, mode, and difficulty.
- New passage preserves controls and swaps passage text.
- Changing duration, mode, or difficulty during a run resets the run and visibly returns metrics to idle.
- No account, leaderboard, certificate verification, server save, or external API affordances appear.
- Error states use both color and decoration: incorrect characters use a colored background plus bottom border.
- Below-tool SEO content is deferred visually below the first work surface.
