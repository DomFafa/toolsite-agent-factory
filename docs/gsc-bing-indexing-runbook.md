# GSC and Bing Indexing Runbook

## Google Search Console

- Verify the domain property.
- Submit sitemap URL.
- Request indexing for the homepage after launch.
- Record submission status in Agent 6 launch report.

## Bing Webmaster Tools

- Verify site ownership.
- Submit sitemap URL.
- Configure IndexNow key if used.
- Record submission status in Agent 6 launch report.

## Sitemap conventions

Default sitemap URL:

```txt
https://<domain>/sitemap-index.xml
```

or, if the starter uses a single sitemap:

```txt
https://<domain>/sitemap.xml
```

The final URL must be recorded in the launch report.
